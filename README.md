# Athulya Ravi — Portfolio

Personal portfolio website of **Athulya Ravi**, Computer Science undergraduate at SRM University and BS Data Science student at IIT Madras.

**Live site:** https://athulyaravi11.github.io/portfolio

## Features
- Interactive 3D particle field (Three.js / WebGL) that changes shape as you scroll: sphere, torus knot, double helix, spiral galaxy
- Click anywhere to send a shockwave through the particles
- CI-style boot intro, scroll progress bar, cursor ring and magnetic buttons
- Experience timeline styled as git commits
- Project cards with 3D tilt and live previews
- Rotating 3D skills globe with category filters
- Interactive terminal (`help`, `whoami`, `projects`, `contact`, …)
- Fully responsive and respects reduced-motion settings

## Tech
HTML, CSS and vanilla JavaScript in a single file, with [Three.js r128](https://threejs.org/) from cdnjs. No build step.

## Run locally
Open `index.html` in a browser, or serve the folder:
```bash
python3 -m http.server 8000
```

## Deploy on GitHub Pages
1. Push `index.html` and `README.md` to the `main` branch of the `portfolio` repo.
2. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, and save.
3. The site goes live at `https://athulyaravi11.github.io/portfolio` in a minute or two.
